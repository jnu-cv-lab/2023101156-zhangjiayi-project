# 相机标定实验说明（棋盘格标定法）

## 一、实验背景

相机标定是计算机视觉中的基础步骤，其目的是确定相机的内参（焦距、主点）和畸变参数，从而将二维图像中的像素坐标与三维世界坐标建立准确的映射关系。本实验采用张正友棋盘格标定法，通过拍摄多张不同姿态的棋盘格图片，使用 OpenCV 完成相机标定。

## 二、实验目标

1. 理解棋盘格角点在世界坐标系与图像坐标系之间的投影关系。
2. 掌握使用 OpenCV 进行相机标定的完整流程。
3. 获取相机的内参矩阵、畸变参数，并评估标定精度。
4. 对图像进行去畸变处理，对比畸变校正前后的效果。

## 三、棋盘格信息

本实验采用打印棋盘格，粘贴于硬纸板上以保证平整。棋盘格由 10×7 个黑白方格组成，内角点数为 9×6（横向9个内角点，纵向6个内角点），方格边长为 20.0 mm（用游标卡尺实际测量）。

## 四、相机信息

实验使用 nova 11 手机的后置摄像头进行拍摄。图像分辨率为 4096×3072 像素，镜头为普通镜头（等效焦距 27 mm），具备一定的广角特性，因此图像边缘存在较为明显的桶形畸变。

## 五、实验流程

1. 准备标定板：在硬纸上打印棋盘格，确保纸张平整、无褶皱。
2. 拍摄标定图片：从不同位置和角度拍摄棋盘格，覆盖画面的九个区域（中心、四角、上下左右边），共拍摄 22 张有效图片。
3. 角点检测：使用 OpenCV 的 `findChessboardCornersSB` 函数检测每张图片中的棋盘格内角点，并对检测到的角点进行亚像素精度优化。
4. 相机标定：调用 `calibrateCamera` 函数，输入世界坐标和图像坐标，计算内参矩阵、畸变参数和外参。
5. 计算重投影误差：将世界坐标投影回图像平面，计算投影点与实际角点之间的像素误差，评估标定精度。
6. 去畸变处理：对一张典型图像进行畸变校正，对比原图与去畸变图的效果。
